# 자치법규 정합성 점검

전북특별자치도교육청 자치법규가 인용한 법령 조문을 **현행 법령과 대조**해,
상위법 개정이 반영되지 않은 조례·규칙·훈령을 소관부서별로 보여주는 화면.

- 대상: 교육청 누리집 법무행정 자치법규 355건 (조례 253 · 규칙 74 · 훈령 28)
- 기준일: 법령 2026.9.21. · 자치법규 2026.9.18.
- 판정 구분: 정비 필요 / 시행 전 정비 / 표기 정비

## 화면 띄우기

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # dist/
```

버셀 배포는 `vercel.json` 그대로 쓴다. framework=vite, 산출물 `dist`.

## 자료가 만들어지는 길

화면이 읽는 자료는 `src/data/issues.json` 하나뿐이다. 만드는 순서는 이렇다.

1. **자치법규 목록·전문** — 누리집 목록(`knd=30001/30002/30003`)으로 대상 확정,
   전문은 [`legalize-kr/ordinance-kr`](https://github.com/legalize-kr/ordinance-kr) 미러에서 받는다.
   (누리집 목록에는 소관부서가 없다. 미러 머리말의 `담당부서`를 쓴다)
2. **현행 법령·개정 이력** — [`legalize-kr/legalize-kr`](https://github.com/legalize-kr/legalize-kr).
   개정 한 번이 커밋 하나라, 특정 시점의 조문을 그대로 꺼낼 수 있다.
3. `analysis/extract.py` — 자치법규 본문에서 「법령명」 제○조 인용을 뽑는다.
   `같은 법`, 약칭(`이하 "법"이라 한다`)을 풀고 부칙은 뺀다.
4. `analysis/index.py` — 인용한 법령명을 미러 경로에 붙인다.
5. `analysis/judge.py`, `analysis/cand.py` — 제정·개정 시점 조문과 현행 조문을 비교해 후보를 걸러낸다.
6. `analysis/data.py` — 사람이 문맥을 보고 판정한 결과를 `issues.json` 으로 쓴다.

스크립트 안의 경로는 만들 때 쓰던 작업 폴더 기준이라, 다시 돌릴 때는 `S = ...` 한 줄을 고친다.

## 한계

- 조(條) 단위 대조. 항·호 번호 이동은 일부만 확인
- 고시·훈령·예규 등 행정규칙 인용은 대조 제외
- 조문 번호 없이 법령명만 인용한 경우는 제명 변경만 확인
- 소관부서 확인 전 1차 결과
